## Deutsch

### Kurzbeschreibung

Dieses Repository enthält ein einfaches, browserbasiertes Werkzeug für die klassische SWOT-Analyse. Es stellt die vier Felder Stärken, Schwächen, Chancen und Risiken als Vierfeldertafel dar und unterscheidet zwischen internen, beeinflussbaren Faktoren und externen, nicht beeinflussbaren Faktoren. Alle Einträge werden ausschließlich lokal im Browser der jeweiligen Nutzerin oder des jeweiligen Nutzers gespeichert. Es besteht keine Verbindung zu einem externen Server und keine Abhängigkeit von einem Konto.

### Dateien in diesem Repository

- `swot-analyse-lokal.html`: das eigentliche Tool. Die Datei lässt sich direkt im Browser öffnen, ganz ohne Installation, oder über GitHub Pages bereitstellen.
- `SWOT-Anleitung.docx`: Kurzbeschreibung und ausführliche Gebrauchsanweisung als Word-Dokument.

### Verwendung

Öffne `swot-analyse-lokal.html` in einem aktuellen Browser. Über die Eingabemaske lassen sich Einträge den vier Kategorien zuordnen, die anschließend im Board erscheinen. Unter der Matrix stehen Funktionen zum Sichern und Wiedereinspielen des Standes als JSON-Datei sowie zum Export als Tabelle, als Word-Dokument oder als PDF zur Verfügung. Die ausführliche Anleitung findest du in `SWOT-Anleitung.docx`.

## English

### Short description

This repository contains a simple, browser-based tool for conducting a classic SWOT analysis. It displays the four fields, strengths, weaknesses, opportunities, and threats, as a four-quadrant matrix, and distinguishes between internal, controllable factors and external, uncontrollable factors. All entries are stored exclusively in the local browser of the person using the tool. There is no connection to an external server and no dependency on an account.

### Files in this repository

- `swot-analyse-lokal.html`: the tool itself. The file can be opened directly in a browser without any installation, or deployed via GitHub Pages.
- `SWOT-Anleitung.docx`: a short description and detailed usage instructions as a Word document (currently in German).

### Usage

Open `swot-analyse-lokal.html` in a current browser. The input form lets you assign entries to one of the four categories, which then appear on the board. Below the matrix, you will find functions to save and reload the current state as a JSON file, and to export it as a spreadsheet, a Word document, or a PDF. Detailed instructions are provided in `SWOT-Anleitung.docx`.
